# 実装が依拠する X100VI の仕様

`src/domain/capabilities.ts` に実装されている値の一覧です。
実機仕様と食い違いを見つけた場合、このファイルではなく
**`capabilities.ts` を直せば全レイヤー（露出計算・バリデータ・AI プロンプト・UI）に波及します**。

## レンズ・シャッター

| 項目 | 値 |
|---|---|
| レンズ | 23mm F2 固定（35mm判換算 35mm 相当） |
| 絞り | F2 〜 F16、1/3 段刻み（19 段） |
| メカニカルシャッター | 30秒 〜 1/4000秒（絞り依存、下表） |
| 電子シャッター | 30秒 〜 1/180000秒 |
| 内蔵 ND フィルター | 4 段 |
| フラッシュ同調 | リーフシャッターのため全速同調 |

### リーフシャッターの絞り依存上限

X100 シリーズ最大の癖であり、本システムが最も注意して扱っている制約です。

| 絞り | メカニカルシャッターの最高速 |
|---|---|
| F2 〜 F2.5 | 1/1000 秒 |
| F2.8 〜 F3.6 | 1/2000 秒 |
| F4 〜 F16 | 1/4000 秒 |

実装: `LEAF_SHUTTER_LIMITS` / `mechanicalFastestSec()`

日中に開放でボケを出す場合、この上限に必ず当たります。システムは
**ND → 電子シャッター併用 → 絞り込み** の順に逃がし、その理由を UI に表示します。

## 感度

| 区分 | 値 |
|---|---|
| 常用 | ISO 125 〜 12800（1/3 段刻み、21 段） |
| 拡張低感度 | ISO 64 / 80 / 100（ダイナミックレンジが狭まる） |
| 拡張高感度 | ISO 25600 / 51200（JPEG 専用） |
| ベース感度 | ISO 125 |

拡張感度は RAW 記録と併用できないため、バリデータが常用域へ引き戻します。

## 露出

| 項目 | 値 |
|---|---|
| 露出補正 | -5 〜 +5 EV、1/3 段刻み |
| 測光 | マルチ / 中央重点 / スポット / アベレージ |
| 手ブレ補正 | ボディ内（IBIS）。カタログ値 最大 6.0 段 |

実装では IBIS の実効段数を **4 段**として扱っています（`IBIS_EFFECTIVE_STOPS`）。
カタログ値どおり 6 段で計算すると手持ち限界が 1/2 秒近くになり、歩留まりが悪化するためです。
さらに手持ちの下限は 1/4 秒でクランプしています。

被写体が動く場合、下限を決めるのは手ブレではなく被写体ブレです。

| 被写体の動き | 下限シャッター速度 |
|---|---|
| 静止 | 手ブレ限界による |
| ゆっくり（歩く） | 1/125 秒 |
| 速い（走る・スポーツ） | 1/500 秒 |

## ダイナミックレンジ

| 設定 | 必要な最低 ISO |
|---|---|
| DR100% | 制限なし |
| DR200% | ISO 250 以上 |
| DR400% | ISO 500 以上 |
| DR オート | 制限なし |

Dレンジ優先（AUTO / 弱 / 強）を有効にすると、ダイナミックレンジ設定と
ハイライト/シャドウトーンはカメラの自動制御になります。バリデータはこの排他を解きます。

## フィルムシミュレーション（20 種）

PROVIA / Velvia / ASTIA / クラシッククローム / PRO Neg. Hi / PRO Neg. Std /
クラシックネガ / ノスタルジックネガ / ETERNA / ETERNA ブリーチバイパス / REALA ACE /
ACROS（+Ye/R/G）/ モノクロ（+Ye/R/G）/ セピア

うちモノクロ系 9 種ではカラー（彩度）とカラークロームエフェクトが効かないため、
バリデータがそれらを送信対象から外します。

各シミュレーションの性格は `src/domain/labels.ts` の `FILM_SIMULATION_NOTES` に記述し、
AI のシステムプロンプトへそのまま渡しています（選定の根拠を与えるため）。
